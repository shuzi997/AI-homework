01实现：参数是怎么被学出来的

核心就四步循环：前向传播算出预测 → 算 Loss 看差多少 → 反向传播算出每个参数的梯度 → 沿梯度反方向更新参数。跑 1000 轮，参数就慢慢"长"到了合适的位置。

mlp.py — 完整可运行代码 
import numpy as np
import matplotlib.pyplot as plt

# ---------- 1. 造一组简单的分类数据 ----------
np.random.seed(0)
X0 = np.random.randn(50, 2) + [0, 0]      # 第 0 类：50 个点，聚在 (0,0) 附近
X1 = np.random.randn(50, 2) + [3, 3]      # 第 1 类：50 个点，聚在 (3,3) 附近
X = np.vstack([X0, X1])                   # 形状 (100, 2)
y = np.vstack([np.zeros((50, 1)),         # 前 50 个标签为 0
               np.ones((50, 1))])         # 后 50 个标签为 1

# ---------- 2. 初始化学习参数 ----------
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

W1 = np.random.randn(2, 5) * 0.5          # 输入层 -> 隐藏层
b1 = np.zeros(5)
W2 = np.random.randn(5, 1) * 0.5          # 隐藏层 -> 输出层
b2 = np.zeros(1)

lr = 0.5                                  # 学习率
losses = []                               # 记录每轮 Loss

# ---------- 3. 训练 ----------
for epoch in range(1000):

    # 前向传播
    h = sigmoid(X @ W1 + b1)              # 隐藏层输出 (100, 5)
    out = sigmoid(h @ W2 + b2)            # 网络预测 (100, 1)

    # 算 Loss（均方误差）
    loss = np.mean((out - y) ** 2)
    losses.append(loss)

    # 反向传播：算梯度
    d_out = (out - y) * out * (1 - out)
    d_W2 = h.T @ d_out
    d_b2 = d_out.sum(axis=0)
    d_h = d_out @ W2.T * h * (1 - h)
    d_W1 = X.T @ d_h
    d_b1 = d_h.sum(axis=0)

    # 梯度下降：更新学习参数
    W1 -= lr * d_W1
    b1 -= lr * d_b1
    W2 -= lr * d_W2
    b2 -= lr * d_b2

# ---------- 4. 看结果 ----------
pred = (out > 0.5).astype(int)
print("最后 Loss:", round(losses[-1], 6))
print("准确率:", (pred == y).mean())

# ---------- 5. 画 Loss 下降曲线 ----------
plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False
plt.plot(losses)
plt.xlabel("训练轮数")
plt.ylabel("Loss")
plt.title("MLP 训练过程中 Loss 的下降曲线")
plt.grid(True, alpha=0.4)
plt.show()

03学习参数：权重自己走成了什么值

这才是「学习参数」的重点。图里是 5 个隐藏神经元连到输出层的权重 W₂，每 10 轮记一次；它们从随机的小数字逐渐分开、拉大，有的变正有的变负——这就是网络在"分配任务"：正权重的神经元负责投赞成票，负权重负责投反对票。

参数数值含义
怎么读这张表：W₂ 里最大的是 +6.04、最小的是 −7.45，绝对值都远大于初始化时的 0.5。 说明这 5 个神经元并不是平均用力，而是被训练成了几个"强特征检测器"。如果权重全都趋近 0，通常意味着学习率太小或者训练不够；如果数值爆炸到几十上百，则是学习率太大。这几个数字落在 5~7 的量级，属于收敛得比较健康的状态。

小结这次作业搞明白了什么
  1. 参数不是魔法：W 和 b 一开始是随机数，每一轮只做一件很小的事——顺着梯度的反方向挪一小步。1000 次小步累积起来，就成了能分类的函数。
  2. Loss 是唯一的指挥棒：网络并不知道"我要把两类点分开"，它只知道把 Loss 变小。分开两类点的能力，是 Loss 下降的副产品。
  3. 可视化比数字有用：只看最终 Loss 是 0.00012，感觉不到什么；但看到决策边界从乱切一条线变成干净的分界，才真的理解"学习"发生了什么。
  4. 21 个参数就够了：这么小的网络就能完美分开两团点。真正难的问题不是参数不够多，而是数据复杂、容易过拟合。
